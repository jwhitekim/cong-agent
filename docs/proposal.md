# 혼잡도 관측 에이전트 제안

## 왜 만드는가

`congestion-llm-gating`은 규칙 트리거로 구간을 고른 뒤 LLM이 한 번 판정한다. 이 프로젝트에서는 에이전트가 저장된 관측값만 보고 살펴볼 구간을 스스로 찾는다. 기존 판정과 트리거 정보는 판단 입력에서 제외한다.

## 무엇을 만드는가

[상위 계약](contract.md) 안에서 세션 하나와 질문 하나를 받아 실행하는 텍스트 에이전트를 만든다. 세션 적재, 조회 도구 4개, 판정 제출, SDK 실행을 순서대로 연결한다. 근거 세그먼트와 판정을 저장하고, 종료 상태와 대화 기록을 남긴다.

capability는 `session-loading` → `query-tools` → `judgment-submission` → `agent-run` 순서로 의존한다. 현재 구현의 동작은 각 명세에, 구현·테스트 상태는 [tasks.md](tasks.md)에 기록한다.

## 범위 밖

- 영상·이미지 분석, GPU 추론, 검출·추적 모델 실행.
- `congestion-llm-gating` 코드 변경과 규칙 트리거 재현.
- 알림 전송 등 대응 권고의 실제 실행.
- 터미널·파일 편집·브라우저를 사용하는 범용 에이전트.
- 여러 세션을 한 번에 분석하는 기능과 자체 LLM 실행 루프.
